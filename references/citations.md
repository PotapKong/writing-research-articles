## Inline citation rules

Use the host environment's citation system when web results are available. In Codex responses, provide source links in Markdown and include a separate Hyperlink Map for editorial use.

1. Every factual sentence derived from a search result must carry an inline citation attached to the most specific noun phrase, figure, or institution name.
2. Follow the active quotation and copyright limits. Paraphrase unless a short direct quote is necessary.
3. One citation per factual claim is the default. If two sources independently confirm a claim, cite both.
4. If a fact comes from an opened primary source, cite the primary source URL, not the aggregator that linked to it.
5. Hyperlink Map is always produced in addition to inline citations — it is separate and for the editor's publication use.

## Hyperlink Map format

After the article, add a section titled **Hyperlink Map**.

## Hyperlink placement rules

1. Hyperlinks must be attached to natural anchor phrases — not random verbs like "read" or "here".
2. Prefer linking the most relevant noun phrase, number, report name, institution name, or specific factual phrase.
3. Do not overlink. One strong link per important factual claim is usually enough.
4. If several sentences in a row rely on the same source, identify the most natural single anchor point.
5. Use the best available source, preferably primary.
